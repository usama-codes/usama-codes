### 🔬 [Second Look](https://github.com/usama-codes/ISIC-2024-Competition) · [Live](https://isic-2024.vercel.app/)
Skin lesion classifier (malignant vs. benign) built on the ISIC 2024 dataset.
- Transfer learning with custom color histograms, LBP texture and contour-based shape features
- Targeted augmentation for class imbalance; **AUC 0.87**
- Recall-prioritised threshold for a screening context
- Quantized to TFLite for fully client-side, zero-upload inference
- Next.js interface with drag-and-drop upload, confidence scores, Firebase scan history and WCAG-accessible design

`Python` `TensorFlow/Keras` `EfficientNetB0` `TFLite` `TF.js` `Next.js`

### 🔎 [Inquire: Search Engine](https://github.com/usama-codes/search-engine)
Search engine over **1.39M+ Medium articles**: an offline Python indexing pipeline feeding a low-latency C++ query engine.
- 521k-word lexicon, forward and inverted indexes split into 50 barrels for parallel queries
- NLTK tokenization and lemmatization, TF-IDF ranking
- Flask ingestion API, C++ ranking engine, React/TypeScript frontend

`C++` `Python` `Flask` `React` `TypeScript` `NLTK`
